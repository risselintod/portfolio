## 🚀 Quick Start

### Prerequisites
- Node.js (v14.0.0 or higher)
- npm (v6.0.0 or higher)
- Modern web browser

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/risselintod/my-web-dev-portfolio.git
   cd my-web-dev-portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm run dev
   ```

4. **Open in browser**
   ```
   http://localhost:3000
   ```

### Available Scripts

```bash
# Development server with live reload
npm run dev

# Production server
npm start

# Performance audit with Lighthouse
npm run lighthouse

# Code formatting
npm run format

# Code linting
npm run lint

# Security audit
npm run audit
```

## 🔧 Customization

### Updating Content

1. **Personal Information**
   - Edit `index.html` for contact details and bio
   - Update `manifest.json` for PWA information

2. **Projects Section**
   - Modify project cards in the projects section
   - Update images in `assets/images/`

3. **Skills Section**
   - Add/remove skill items and icons
   - Update skill categories as needed

### Styling Customization

1. **Colors**: Modify CSS custom properties in `:root`
2. **Typography**: Update font imports and variables
3. **Spacing**: Adjust spacing scale variables
4. **Animations**: Customize transition and animation durations
